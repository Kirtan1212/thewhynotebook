Privacy policy

Last updated: 7 November 2026

This policy covers The Why Notebook uploader (Google Cloud project why-notebook-pipeline), a private tool that uploads and manages videos on The Why Notebook's own YouTube channel. It is not offered to the public, and the only account it connects to is the channel's own Google account.

What the tool accesses

  • It uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails, playlists and publish times, and read basic information about the channel's own videos.
  • It does not access any other YouTube user's account, and it does not collect information about viewers.

What is stored, and where

  • A Google OAuth refresh token for the channel's account, stored privately in the tool's own configuration and never published or shared.
  • A log of the channel's own uploads (video IDs, titles, dates) used to link Shorts to full videos.
  • No personal data about anyone else is stored, sold or shared with third parties.

YouTube and Google

The tool uses YouTube API Services. By using it, the channel agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Access can be revoked at any time from the Google account's security settings: myaccount.google.com/permissions.
